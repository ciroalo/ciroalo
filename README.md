**Some stuff I built:**
- [**leetcode-vault**](https://github.com/ciroalo/Leetcode-vault) - A storage for all the Leetcode problems I have solved along their explanations.
- [**mod-conversor**](https://github.com/ciroalo/mod-conversor) - A conversor of one or multiple `.MOD` files to `.mp4` files.
- [**safeid**](https://github.com/ciroalo/safeid) - An offline tool (also made it macOS app) that converts ID photos into a watermarked PDF to help safely share sensitive documentation. Built as a professional-style project with a full architecture process: project-charter, PRD, ADRs, domain modeling, hexagonal architecture and automated tests.
- [**tree-it**](https://github.com/ciroalo/tree-it) - A configurable CLI tool for generating one or multiple directory trees with .treeignore profiles, .gitignore fallback. Built in Rust.
